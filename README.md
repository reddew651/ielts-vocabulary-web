# IELTS 听力词汇听写 (Vocabulary Practice)

一个极致简约**纯前端**雅思听力词汇听写工具。  
帮助你沉浸式进行听力拼写练习，无需复杂配置，点开即用。

---

## 📖 该怎么用？(使用说明)

### 🧑‍🎓 给学习者 (如何练习)
1. **选择题库**：在界面左侧边栏，点击展开对应的 `Chapter`，选择你想听写的 `Test Paper`。
2. **播放音频**：顶部会出现音频控制栏，支持**播放/暂停**以及 **1.2x/1.5x 倍速**调节。
3. **开始听写**：根据音频和中文释义，在下方的白色学习卡片中输入英文单词。按 `Enter` 键可快速跳到下一个输入框。
4. **提交检查**：听写完成后，点击右上角的 **“提交检查”**：
   - 🟢 **正确**：卡片变为柔和绿色。
   - 🔴 **错误**：卡片变为红色预警，带有删除线，并在一旁显示正确的拼写。
5. **错词与复习**：点击右上角 **“错词本”** 会弹出一个类似 macOS 窗口的独立面板，收录你的所有错词，并且支持**一键导出 Markdown** 方便打印或导入其他笔记软件（如 Notion/Obsidian）。
6. **进度防丢失**：在左下角有“导出备份”和“导入恢复”按钮。由于数据保存在浏览器，换电脑或清缓存前，记得导出一份备份。

### 💻 给开发者 (本地运行)
如果你想自己在电脑上跑起来或者修改代码：
1. **安装环境**：请确保电脑有 `Node.js` 和 `Python`。
2. **装依赖**：
   ```bash
   npm install
   ```
3. **更新题库 (可选)**：如果修改了 `1.txt` 里的题目，运行以下脚本重新生成 JSON 题库：
   ```bash
   python parse_words.py
   ```
4. **启动项目**：
   ```bash
   npm run dev
   ```
   *(随后在浏览器打开 `http://localhost:5173` 即可)*
5. **项目打包**：
   ```bash
   npm run build
   ```

## 🛠 技术实现分析

本项目采用了 **“Python 数据预处理 + 轻量级前端工程化”** 的架构，主打一个**快、轻、优雅**。

1. **核心前端层 (Vite + Vanilla TypeScript)**：
   - 没有使用 React / Vue 等重型框架，而是直接使用原生 DOM 操作（`main.ts`），这使得打包体积极小，运行性能满配（毫秒级热更新）。
   - 代码按职责分离：`audioPlayer.ts`（音频控制）、`state.ts`（状态和存储）、`main.ts`（UI渲染）。
2. **数据流与架构**：
   - **零服务端/零数据库**：通过 Python 脚本 (`parse_words.py`) 将人类易读的 Excel/TXT 题库(`1.txt`) 离线预编译为结构化的 `public/data.json`。前端启动时直接 Fetch 此静态 JSON 文件。
   - 这不仅省去了后端的开发和服务器成本，也让部署静态网页（如 GitHub Pages）变得极其简单。
3. **状态持久化 (localStorage)**：
   - 在 `state.ts` 中拦截一切用户的做题行为（正确题数、错题本、测试历史等），实时序列化写入浏览器的 `localStorage`。实现了离线可用并保护隐私。
4. **UI / UX 界面设计**：
   - **Apple 风格 / 毛玻璃拟物化 (Glassmorphism)**：使用 CSS3 的 `backdrop-filter: blur(20px)` 搭配半透明背景色，实现了极具 macOS 质感的侧边栏与导航栏。
   - **卡片式布局**：中间做题区域限制最大宽度 (`max-width: 800px`) 并设计了独立的卡片和光晕聚焦效果，减少视觉干扰，从而创造一个**克制、专注**的学习环境。
5. **自动化 CI/CD**：
   - 接入了 GitHub Actions。每次你在本地修改了 `1.txt` 并 Push 到仓库，云端会自动执行 Python 脚本解析数据，并自动打包 Vite 部署到线上，实现了真正意义上的“改库即上线”。
